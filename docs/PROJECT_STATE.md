# PROJECT_STATE — SYCH FPV SCANNER: сайт-інструкція

Last updated: 2026-10-05 by claude-cloud-governance (audit from 96ba710f1af6)

## Що це

Публічний статичний сайт-інструкція до закритого бета-тесту застосунку
SYCH FPV SCANNER (приймач аналогового FPV-відео на HackRF One + телефон).
Опис і контекст — у [`README.md`](../README.md); тут не дублюється.

Код застосунку в цьому репозиторії не лежить (див. README).

## Мета

- Дати бета-тестерам одну самодостатню сторінку: перший запуск, підсилення,
  режими, мережевий перегляд, помилки й що надсилати назад.
- Тримати сторінку в git, щоб вона не залежала від одного сервера.

## Поточний стан

- 2 коміти в `main`, останній — 2026-09-27 (інструкція 0.3.0).
- 2 знімки екрана з емулятора, без плати (спектр/картинка порожні — так і підписано).
- 6 місць під знімки — пунктирні заглушки (`figure.pending`), свідомо не замінені макетами
  (пояснення в README).
- Шрифти підтягуються з Google Fonts; решта — inline у `index.html`.
- CI, збірки, тестів немає — це не потрібно для однієї статичної сторінки.

розділ «Як оновлювати»). Тобто правки тексту варто робити там, а не лише тут.

## Збірка / тести / запуск

- Збірки немає. Перегляд: відкрити `index.html` у браузері або
  `python3 -m http.server` у корені репо.
- Публікація: GitHub Pages з `main` (за README; налаштування не перевірені).

### Single-writer guard

`tools/project_guard.py` у цей публічний репозиторій **навмисно не додано**.
Правила з `AGENTS.md` (fetch перед правкою, замок `agent-lock`, commit + push + verify)
діють; guard можна запускати з репозиторію `mstekh/tooling`
(`governance/templates/tools/project_guard.py`) із кореня цього репо, або
виконувати ті самі кроки вручну (див. `AGENTS.md`, розділ 3).

## Наступні кроки

1. Замінити 6 пунктирних заглушок живими знімками з реальним сигналом
   (може зробити лише оператор із платою).
2. За потреби замінити знімки з емулятора на живі.
3. Оновлювати копію сторінки після кожної збірки, що змінює рядки стану,
   кнопки чи номер версії.

  чи потрібні вони, UNKNOWN.
